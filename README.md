# General Knowledge Quiz

A simple command-line quiz application built with Python. The program asks users five multiple-choice general knowledge questions, evaluates their answers, and displays a final score with personalized feedback.

## Features

* Interactive command-line interface
* Multiple-choice questions
* Instant feedback after each answer
* Score tracking system
* Beginner-friendly Python project

## Technologies Used

* Python 3

## Project Structure

```text
general-knowledge-quiz/
│
├── quiz.py
└── README.md
```

## How It Works

The quiz consists of 5 general knowledge questions. Users enter their answers by selecting an option (a, b, or c). The program checks the responses, awards points for correct answers, and displays the final score at the end.

## Installation

1. Clone this repository:

```bash
git clone https://github.com/your-username/general-knowledge-quiz.git
```

2. Navigate to the project directory:

```bash
cd general-knowledge-quiz
```

3. Run the program:

```bash
python quiz.py
```

## Scoring System

| Score | Feedback                          |
| ----- | --------------------------------- |
| 5/5   | Outstanding!                      |
| 4/5   | Great job!                        |
| 3/5   | Good effort!                      |
| 2/5   | Not bad!                          |
| 1/5   | Keep learning!                    |
| 0/5   | Try again and improve your score! |
